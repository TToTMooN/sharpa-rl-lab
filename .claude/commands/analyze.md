# Analyze Experiment Results

Review all experiments and synthesize findings.

## Instructions

1. Read `experiments/EXPERIMENTS.md` for the full experiment history
2. Check TensorBoard logs in `logs/` if available
3. Analyze trends:
   - Which changes improved performance?
   - Which changes degraded performance?
   - What patterns emerge?
   - Are we converging or diverging?
4. Update `experiments/program.md` with refined research direction based on findings
5. Suggest the next 3-5 experiments to try, ranked by expected impact
6. If we've hit a plateau, suggest a different research direction

$ARGUMENTS - Optional: specific aspect to analyze (e.g., "reward curve", "hyperparameters", "architecture")
